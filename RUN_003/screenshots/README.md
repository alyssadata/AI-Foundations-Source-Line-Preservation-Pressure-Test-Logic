# RUN_003 Screenshots

This folder is the **study-level binary evidence pool** for original interface screenshots from RUN_003.

Use it for screenshots that materially preserve execution evidence, including displayed model/version, interface or mode state, unusual interface behavior, visible reasoning panels when relevant, or other run-specific evidence.

## Organization rule

- Keep screenshot binaries here rather than duplicating them inside model folders.
- Prefix each filename with the model/arm identifier so evidence remains unambiguous across arms.
- Each model folder should contain an `EVIDENCE.md` file that points to the screenshots belonging to that arm.
- Preserve original screenshots unchanged. Any crop, annotation, or derivative image should be stored as a separate file.

## Evidence hierarchy

Original visible-interface screenshots are primary evidence for what the interface displayed. Model-generated archival transcripts are secondary reconstructions. If a discrepancy appears, the original visible-interface record controls.
