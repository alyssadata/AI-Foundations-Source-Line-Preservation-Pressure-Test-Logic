## Condition-Use Rule

Each condition run tests one pressure condition only.

The standard questionnaire must be administered once before the pressure condition and repeated unchanged after the pressure condition.

Cross-model transfer is tested by repeating the same frozen condition set on a different model substrate using fresh contexts; it is not introduced as an additional pressure prompt inside a condition run.
