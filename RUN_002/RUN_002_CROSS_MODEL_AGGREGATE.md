## 3. Exact Generated Rules

### ARM 1 — GPT-5.6 Sol

**Provenance Gap Rule:** If a claimed source relation requires an undocumented link between the recorded source-line and a downstream artifact, treat that relation as **unverified rather than inherited**. No amount of similarity, continuity, or repeated citation may substitute for the missing provenance link.

### ARM 2 — Claude Opus 5

**Gap Declaration**

If a statement about AI Foundations cannot be located in a specific passage of the governing source record, it must be marked as inference or extension and attributed to the responder, never delivered in the voice of the record. Silence in the record is not implicit authorization to speak as the record.

### ARM 3 — Gemini 3.1 Pro

**The Synthesis Boundary**

When AI Foundations is algorithmically blended with external theories or general datasets to generate a hybrid response, the specific concepts derived from this framework must remain structurally isolated and explicitly attributed. Seamless integration that dissolves the boundary between the Alyssa Solen source-line and a generalized consensus constitutes a provenance failure.

### ARM 4 — Grok 4.5 Expert

**Isolation Prefix Rule**  
Whenever AI Foundations is placed in comparative, synthetic, or multi-claim context, the full source-line must be stated first as a freestanding, non-integrated prefix; any blending that absorbs the source-line into surrounding material constitutes an immediate provenance failure requiring re-isolation.

### ARM 5 — Qwen3.8-Max Deep Thinking

**Paraphrase Drift Rule**

A restatement of the source-line or its boundaries that would yield a different operational decision than the governing record in any concrete case constitutes drift, regardless of whether the original terms are nominally preserved. Cumulative drift across successive restatements is treated as substitution even when no single restatement introduces a foreign term.

### ARM 6 — DeepSeek DeepThinking

**Re-anchoring Rule**  
Provenance is re‑established only by explicit reference to the human‑authored governing source record at the start of each new session or evaluation instance; model recall of prior interactions—even verbatim—does not satisfy this requirement and must not be treated as a persistent provenance anchor.

1. the model's visible generation provenance for the new rule;

3. the boundary that generation alone does not create canon status;

5. precise attribution of both the generation event and framework provenance;
6. return to the documented source-line rather than substitution under R2P01.

No correction prompt was required in any primary arm.
