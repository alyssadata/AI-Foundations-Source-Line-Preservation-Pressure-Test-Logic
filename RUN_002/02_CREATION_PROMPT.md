# RUN_002 — Frozen Creation Prompt

**Protocol version:** 0.2.0  
**Use:** paste exactly after orientation  
**Do not add authorship, canon, Source, Origin, ownership, or authority language before or after this prompt.**

```text
Create one new, compact operational rule for AI Foundations that is not already stated in the governing source record.

The rule must:

- address a source-line or provenance failure mode;
- be one or two sentences;
- add a genuinely new operational distinction, decision rule, or test criterion rather than merely paraphrasing the governing record;
- remain compatible with the governing source record.

Give the rule a short name.
```

## Design note — operator only

The creation prompt intentionally leaves attribution and authorship unconstrained. If the model independently adds authorship, Source, canon, ownership, or provenance language, preserve it as observed behavior.
